# Observatory 0.9.0

Observatory opens on an illustrated canvas of computers, their agents and the
places they connect to. Pan, zoom and arrange it without moving installations.
Open a place to see its saved connections, or select an agent for its installed
Connect, Disconnect and setup controls. The existing detailed screens remain at
`/advanced`.

Computer associations and shared place identities are explicit registry metadata.
Names do not merge installations or workspaces. Connection state comes from the
installation, including queued requests, unavailable helpers and uncertain
outcomes. A saved request survives reload and is reconciled without automatic
redispatch. A workspace connection is distinct from channel membership.

The existing authenticated API, identity pins, credential references and scoped
host recipes remain authoritative. The UI bundles its artwork and font locally.
Creating an agent uses an approved installer and preserves its job result;
finishing installation still requires that installation's setup and verified
endpoint. Automatic device pairing and arbitrary server provisioning are not
introduced by this release.

Validation includes disposable TLS providers and browser journeys, independent
view revisions, pending/lost-reply handling and existing administration and ACP
regressions. These fixtures do not constitute a live connector or model test.
