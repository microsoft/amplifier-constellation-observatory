# Observatory 0.13.0

Local agent setup continues inside Observatory after installation. You can
connect a supported model account or enter a provider key, review the selected
model, explicitly start your agent, and continue into Slack setup. Existing
engines, account settings, sessions and paused connections are preserved.

Windows and macOS consumer packages carry the reviewed Slack connector needed
for this flow. Observatory creates a separate private connector installation;
the connector owns its authorization, credentials and background service. Slack
approval and workspace selection remain explicit, including any approval your
workspace administrator requires. No model request is sent just to check setup.

Saved setup can be reopened after leaving the page. Lost replies are reconciled
against the original installation and request; setup and Slack actions are not
automatically repeated. Changed agent identities or unavailable observations
disable further actions until their state is established.

Background setup helpers use windowless Windows launches while preserving their
captured input and output. Package qualification includes the native agent and
connector lifecycle as well as browser interaction; external account consent is
a separate user step.

These remain unsigned preview applications. Normal operating-system download
and launch protections still apply. The new bundled Slack setup flow is offered
on Windows and macOS; existing Linux observation and management remain available.
