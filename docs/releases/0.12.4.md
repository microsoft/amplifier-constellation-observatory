# Observatory 0.12.4

Open **Approvals** from the main view to choose **Ask** or **Automatic** for
all registered agents in one place. Review the complete list, then apply the
change. Each agent keeps its own approval policy and saved rules; Observatory
does not become a required approval service.

Automatic accepts supported permission requests without prompting. It does
not turn on an engine's Full access mode, override operating-system access,
or change tool restrictions and work budgets. Ask keeps existing remembered
rules. Use an agent's settings link to review or revoke those rules.

The result lists agents that confirmed the setting and any that were offline,
unsupported, changed during the request, or need administrator access. An
interrupted response is recovered by reading the original operation; uncertain
writes are not automatically sent again. Newly registered agents retain their
own settings until another explicit change.

Policy management requires Observatory administrator access and a trusted
administrator connection to each supporting Agent Instance. This release
does not change existing modes, grant connection permissions, or enable
remembered approvals for engines that do not provide a trusted request scope.

Fresh desktop packages include published Instance 0.22.10. Constellation
Computer 0.3.3 carries the same exact package pins. Existing installations,
selected engines, models, conversations, and credentials are retained.
