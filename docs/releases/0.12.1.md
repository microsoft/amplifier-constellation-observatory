# Observatory 0.12.1

This patch preserves the intent and attribution of interactions with independently
owned agents. It includes the changes accepted since 0.12.0 in PRs 25, 26 and 27.

Later draft and filter edits survive earlier saves from the same rendered form,
including when a response arrives late. Changes from another controller or a
different resource still refuse stale input without replaying it. Saved context
retains the recorded author separately from the agent's display label.

Management observations remain tied to the endpoint revision that was checked.
Changing that endpoint hides its stale observation while preserving the original
record. Management errors distinguish refusal, conflict and busy responses from
an unconfirmed write outcome.

For agents advertising the compatible ordinary-input source/work profile,
Observatory preserves the original input identity and can explicitly inspect its
retained work references. Inspection restores the same execution session without
sending another prompt, answering an approval or resuming queued input. An absent
receipt does not authorize a retry, and cached work observations remain visible
only to the original input actor. Agents without this optional profile continue
to use the existing ACP path.

Existing endpoints, credentials, conversations and view records are preserved.
This release changes no dependency, machine-helper version or bundled Instance
pin. It does not update the engines, models or installations connected to
Observatory. The normal update path checks the new package and preserves the
existing installation; an uncertain update outcome must be reconciled before
another action.

The source fixes were checked with 169 Rust tests and 59 browser cases, including
held save responses, peer conflicts, source-inspection privacy and lost replies.
The versioned release packages undergo the normal six-platform build, packaging,
native setup and replacement checks. These checks do not establish signing,
notarization or clean-machine acceptance; existing unsigned-package limits remain.
