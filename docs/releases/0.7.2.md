# 0.7.2 — Ignore empty ACP control envelopes when choosing a reply

An empty text update can carry an input receipt without being an assistant message.
Reply assembly now ignores its text before assigning message order, changing a
phase, consuming message capacity, or inserting legacy tool separators. This
prevents an early receipt from making an older draft win over the current reply.
Input receipt processing remains independent and unchanged.

Regression tests cover empty identified/unidentified updates, empty phase updates,
and bounded capacity under repeated metadata-only updates.
