# Constellation Computer 0.3.4

This matching helper is distributed with Observatory 0.12.6 desktop packages
and setup downloads. New agent installations use the published Instance
0.22.12 packages, which bundle Runtime 0.15.12.

Observatory and this helper use the same fixed package pins. An older helper
refuses requests for these different packages; use the matching helper for
new agent setup. Existing agents keep their selected engines, models,
credentials, sessions and approval settings.
