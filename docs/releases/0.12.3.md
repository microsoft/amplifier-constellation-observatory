# Observatory 0.12.3

Observatory labels an agent's engine from the identity the agent reports. It
does not assume that every connected agent uses this repository's default
engine or guess an engine from an unrelated installation entry.

New Linux source installations restart after another program terminates the
service with SIGTERM. A stop through systemd and the application's own clean
exit remain stopped, preserving managed-update behavior. Existing-service
adoption accepts the exact old or new generated unit text without rewriting
it; other modifications still refuse adoption. Updating the application does
not change an installed unit or remove local overrides. See
[existing-service adoption](../existing-service-adoption.md) for that separate
owner operation.

Fresh desktop packages pin published Instance 0.22.8, including Runtime 0.15.9.
The matching Constellation Computer helper is 0.3.2 because its fixed install
requests embed those same package hashes. Existing pairings, connected agents,
selected engines and models remain unchanged. These packages do not perform a
live rollout or establish clean-machine, signing or notarization acceptance.
