# Constellation Computer 0.3.2

This helper uses the published Instance 0.22.8 package pins shared with
Observatory 0.12.3. Those fresh-install bundles include Runtime 0.15.9.
Installation still requires the helper's locally approved install access and
the exact package hash for that computer.

Updating the helper preserves pairing identities and permissions. It does not
install an agent, update an existing Instance, or change its engine or model.
Existing unsigned and unnotarized package limitations remain.
