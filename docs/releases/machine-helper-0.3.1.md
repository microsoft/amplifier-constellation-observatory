# Constellation Computer 0.3.1

This helper uses the exact published Instance 0.22.7 package pins shared with
Observatory 0.12.2. Those fresh-install bundles include Native Runtime 0.15.7.
An installation request still requires the helper's existing locally approved
install access and must match the fixed package hash for that computer.

Existing pairing identities, permissions and installations are preserved.
Updating this helper does not install an agent, update an existing Instance or
change a selected engine or model. Original computer-helper 0.3.0 downloads
remain unchanged. The normal six-platform helper packaging and setup checks
apply; unsigned and unnotarized package limitations remain.
