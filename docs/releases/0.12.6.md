# Observatory 0.12.6

Desktop setup packages include Instance 0.22.12 with Runtime 0.15.12. The Runtime
update preserves the full conversation while omitting Anthropic reasoning that
no longer matches its original context, and projects refreshed context with
the request that carries it.

The desktop packages distribute matching Constellation Computer 0.3.4 helpers
with the same Instance package pins for setup on paired computers. Use the
matching helper before requesting a new agent from this Observatory version;
an older helper refuses the different package.

Existing agents retain their selected engines, models, credentials, sessions
and approval settings. Their enrolled updaters manage engine installation
separately from Observatory.
